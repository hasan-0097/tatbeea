# Contributing

Thanks for helping! Issues and pull requests are welcome in Arabic or English.

1. Fork and clone the repo.
2. Make your change in `src/tatbeea/` and add a test in `tests/`.
3. Run `python -m unittest discover -s tests` (no dependencies needed).
4. Open a pull request describing what the change normalizes and why.

Please keep the library dependency-free and keep every step optional in
`normalize()`.
